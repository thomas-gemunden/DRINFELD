## Task 2: Minimal implementation

**Files:**
- Create: `extraspecial_orbifolds/scripts/iscoboundary2_hap.g`

- [ ] **Step 1: Write the implementation**

```gap
# HAP-native replacement for IsCoboundary2 using the bar-resolution
# boundary maps already constructed for H.
LoadPackage("hap");

IsCoboundary2HAP := function(H, c, m)
  local R, K, n, cVec, eltsList, i, j;
  R := ResolutionFiniteGroup(H, 3);
  eltsList := AsList(H);
  # Build c as a 2-cochain on the bar resolution by evaluating on
  # the standard pair-of-elements basis.
  cVec := List(eltsList, h1 -> List(eltsList, h2 -> c(h1, h2) mod m));
  # Use HAP's exactness decision on the resolution. Implementer:
  # consult HAP docs for the precise function name in your installed
  # version (candidates: `Cocycle`, `CR_Cocycles`,
  # `IsCocycleACoboundary`).
  return HAPIsBoundaryOnResolution(R, cVec, 2, m);
end;
```

> **Implementer note.** `HAPIsBoundaryOnResolution` is a placeholder for the actual HAP function name. Consult `?HAP` in GAP and the HAP manual chapter on group cohomology to identify the correct primitive — the available exactness deciders depend on the installed HAP version. The correct decision is "is the 2-cochain `cVec` a coboundary mod $m$ in the bar complex of $R$?".

- [ ] **Step 1: Write the benchmark**

```gap
# Compares wall-clock of IsCoboundary2 vs IsCoboundary2HAP on a
# centraliser of order 64 (E_+(3) non-central).
Read("transgression_kernel.g");
Read("iscoboundary2_hap.g");

G := SmallGroup(128, 2326);
gRep := Representative(ConjugacyClasses(G)[3]);  # a non-central class
C := Centralizer(G, gRep);
Assert(0, Order(C) = 64);

setup := SetupCohomology3(G);
vec := List([1..setup.num_generators], j -> 0); vec[1] := 1;
omega := StandardCocycleOf(setup, vec);
c_g := CGCocycleFunc(omega, gRep);

# Warm both functions
_ := IsCoboundary2(C, c_g, setup.exponent);;
_ := IsCoboundary2HAP(C, c_g, setup.exponent);;

t0 := Runtime();
for i in [1..3] do _ := IsCoboundary2(C, c_g, setup.exponent);; od;
t1 := Runtime() - t0;

t0 := Runtime();
for i in [1..3] do _ := IsCoboundary2HAP(C, c_g, setup.exponent);; od;
t2 := Runtime() - t0;

Print("Baseline: ", t1, " ms / 3 calls = ", t1/3, " ms/call\n");
Print("HAP:      ", t2, " ms / 3 calls = ", t2/3, " ms/call\n");
Print("Ratio:    ", Float(t2)/Float(t1), "\n");
```

## Template usage notes for agents picking up other issues

When you (an agent) pick up any issue from the workstream design:

1. Replace **Goal**, **Architecture**, **Tech Stack**, and **Acceptance criteria** with the values from your assigned issue.
2. Decompose into 3–6 tasks, each producing a self-contained commit. Aim for a failing test first, minimal impl, expanded regression, benchmark (if applicable), close.
3. Each step is one action of 2–5 minutes.
4. If your issue has no obvious testability (e.g. doc-only issues like W-1a), skip the failing-test pattern and structure as outline → draft → revise → commit.
5. Math-heavy issues (e.g. the Q workstream) may need a "verify against published reference" step before the implementation step.
6. Always finish with `gh issue close <N>` and `relabel_on_close.sh <ID>` so downstream issues unblock.
